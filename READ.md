# Python Quiz App (OOP)

A command-line quiz application built with Python using Object-Oriented Programming principles.

## Features
- Supports both Multiple Choice and True/False questions
- Questions loaded dynamically from a JSON file
- Answer by typing the number (MCQ) or full text
- Instant feedback per question
- Final score tracking

## Tech Stack
- Python 3
- JSON for data storage
- OOP (Question, QuizBank, Quiz classes)

## How to Run
```bash
python quiz.py
